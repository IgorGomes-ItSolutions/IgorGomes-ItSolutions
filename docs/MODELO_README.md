# Modelo de README para novos projetos

Copie e adapte as seções abaixo. Remova o que não se aplicar e substitua as orientações por informações verificáveis.

## Nome do projeto

Descreva em duas frases o problema e a entrega.

## Situação atual

Informe se é estudo, protótipo ou aplicação em uso. Separe o que foi implementado, executado e validado do que está planejado.

## Tecnologias e estrutura

Liste apenas tecnologias presentes. Explique as pastas existentes e o arquivo de entrada.

## Como executar

Declare pré-requisitos, dependências, configuração sem segredos reais, comandos e resultado esperado. Explique se a execução altera dados ou consome recursos de nuvem.

## Validação e evidências

Informe os comandos de testes, resultados observados e links para evidências. Uma captura não substitui uma instrução reproduzível.

## Decisões e limitações

Explique as escolhas relevantes, restrições conhecidas e usos ainda não validados.

## Próximos passos

Use uma lista curta de entregas futuras, sem apresentá-las como prontas.

## Autoria e apoio de IA

Descreva seu papel, a origem do laboratório quando aplicável e o apoio de ferramentas de IA. Informe como os resultados foram verificados.
